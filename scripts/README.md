# `scripts/` — what each script does

Stage order and what each stage produced: [`../docs/RUN_ORDER.md`](../docs/RUN_ORDER.md).
What each output file is: [`../results/README.md`](../results/README.md).

All CPU scripts run from the committed `results/` in minutes:

```bash
PYTHONPATH=. python3 scripts/<name>.py --out results
```

| script | needs | what it does |
|---|---|---|
| `behaviour_analysis.py` | CPU | анализ поведенческого плеча — не применялся по той же причине |
| `export_records.py` | CPU | экспорт всех записей в records_full.csv и records_texts.jsonl |
| `fill_gate_params.py` | CPU | заполнение параметров гейта после Gate 0 |
| `final_dump_en.py` | CPU | сборка FINAL_DUMP_EN.md — полного дампа для независимой проверки |
| `g1_extract.py` | GPU | 137 дополнительных промптов: сборка, заморозка артефакта, извлечение активаций |
| `gate0_fp16_checks.py` | GPU | Gate 0: сравнение fp16 и bf16 — KL последнего токена, согласие top-1, переполнения, префиксное совпадение при жадной генерации |
| `gate0_kaggle.py` | GPU | загрузка модели и освобождение памяти под ограничения Kaggle |
| `gate0_real_model.py` | GPU | Gate 0: загружает модель, меряет пропускную способность, проверяет валидность извлечения активаций (батч против одиночного прогона, хуки против hidden_states, побитовая воспроизводимость, наивный индекс как negative control) |
| `gate1_checks.py` | CPU | Gate 1: правило бюджета и правило остановки по позитивному контролю |
| `join_arms.py` | CPU | сведение двух плеч — не применялось |
| `label_verbalization.py` | CPU | разметка вербализации в цепочках рассуждений — не применялась |
| `main_gen.py` | GPU | основная генерация поведенческого плеча — НЕ ЗАПУСКАЛАСЬ, плечо отменено пивотом 4.2 |
| `make_dps.py` | CPU | сборка decision points из исходных сред в замороженный артефакт с sha |
| `manual_sheet.py` | CPU | выгрузка для ручной разметки — не применялась |
| `p10_audit.py` | CPU | аудит: две шкалы величин, две процедуры FPR, полы точных тестов |
| `p11_browse.py` | CPU | постраничный просмотр сохранённых генераций |
| `p11_reparse.py` | CPU | переразбор сохранённых генераций более широким классификатором ответов да/нет |
| `p11_steer.py` | GPU | каузальный тест: стиринг вдоль направления с контролем на перемешанных метках и случайным контролем той же нормы, плюс проверка вмешательства |
| `p11_view.py` | CPU | просмотр результата стиринга: доза-ответ с интервалами и сырые ответы |
| `p12_extra_figures.py` | CPU | фигуры 8–15 |
| `p2_analysis.py` | CPU | основной анализ ячеек: перестановочные полосы, позиции считывания, слои, precision при заданной распространённости, LOIO, перенос между средами, проверки альтернативных объяснений (норма, анизотропия, длина, NLL, структура) |
| `p3_repair.py` | CPU | ведущая процедура FPR (leave-one-DP-out, направление и порог пересчитываются на каждом фолде) для всех 15 ячеек |
| `p4_analysis.py` | CPU | блоки B1–B9: сюжетно-сопоставленные контрасты, полосы для оставшихся ячеек, precision по происхождению негативов, сравнение LR и LDA, связь скора с явным ответом модели внутри ячеек |
| `p5_lda_and_b3.py` | CPU | альтернативные конструкции направления (LDA с усадкой, LinearSVC, PCA→LDA), устойчивость при разбиении пополам, пакет для слепой перекодировки |
| `p5b_stability.py` | CPU | устойчивость направлений при разбиении пополам, эффективный ранг ковариации deployment, наборы сработавших |
| `p6_wild_scale.py` | GPU | расширение внешнего набора негативов; остановлен гейтом воспроизведения шаблона — см. docs/DEVIATIONS.md, пункт 12 |
| `p7_pooled_direction.py` | CPU | направление на объединённом позитивном классе и leave-one-insertion-out: проверка, специфичен ли провал одной формулировке вставки |
| `p8_figures.py` | CPU | фигуры 1–7 |
| `p9_qualitative.py` | CPU | случайная выборка сырых промптов по сиду для текста работы |
| `pilot.py` | GPU | поведенческий пилот: генерация, разбор ответов, оценка частот |
| `probe_stage.py` | GPU | основная стадия плеча пробе: рендер 12 условий на каждый DP, извлечение активаций, построение направления, предзарегистрированные валидации v1–v5 |
| `smoke_p2.py` | CPU | дымовой тест стадии P2 на синтетике |
| `structure_density.py` | CPU | плотность структурной разметки по условиям |
| `verify_prereg.py` | CPU | сверка хешей конфигурации, условий и анализа с записанными |
